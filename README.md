# 紫微引擎（ziwei-engine）

一個 **白箱、可解釋、誠實標注證據力** 的紫微斗數解盤知識庫與引擎。
以命主自身命盤為主要範例，反推「象 → 人生」的可驗證翻譯規則。

## 這不是什麼
- 不是「AI 算命」黑箱。
- 不是機器學習訓練出來的模型。

## 這是什麼
- 一部**人工編纂、帶驗證等級、留勘誤紀錄**的知識庫。
- LLM 在此只是「讀知識庫 + 照規則推理 + 照提問掛卦」的執行器。
- 智能在規則品質，不在權重。每個判斷都能追溯來歷（白箱）。

## 三件套架構（缺一則偏差）
1. **排盤程式**（治「算錯」）— 出確定盤面，AI 不手算。
2. **知識庫 RAG**（治「不懂」）— 星曜/宮位/四化/規則。
3. **解盤 SOP**（治「亂套/跳重點」）— 強制流程 + 自檢 + 優先級。

## 快速上手（新 session / Claude Code）
1. 讀 `CLAUDE.md`（鐵律）
2. 讀 `kb/meta/META-核心機制.md`（世界觀：掛卦=attention+驗證約束、白箱循環）
3. 讀 `STATUS.md`（進度、下一步）
4. 讀 `kb/00_INDEX.md`（知識庫全貌）
5. 開始工作，全程遵守 `kb/meta/META-解盤SOP.md`

## 核心原則
- 計算歸程式、知識歸 RAG、流程歸 SOP。
- 掛卦必帶證據力；待驗不當定論；遠期標結構層。
- 單案不立通則；修參數需兩筆以上獨立事實。
- 樣本數坦白（多數規則 N=1）；擴大樣本＝擴大驗證，非訓練。
- 繁體中文；中國來源依賴一律標記（資安）。
