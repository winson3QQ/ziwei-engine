# 宮位系統：盤面的結構關係

## 十二宮序（命宮起，逆時針為陰男逆行方向）
命宮 → 兄弟 → 夫妻 → 子女 → 財帛 → 疾厄 → 遷移 → 交友 → 官祿 → 田宅 → 福德 → 父母

## 三方四正
- **三方**：本宮 ＋ 對宮 ＋ 三合二宮。
- 命宮三方四正 = 命、財帛、官祿（三合）＋ 遷移（對宮）。
- 判一宮吉凶，看其三方四正的星曜與四化總和，非只看本宮。

## 六合（暗合）— 兩宮暗中相通
```
子丑、寅亥、卯戌、辰酉、巳申、午未
```
釋義：一宮之事暗渡另一宮。例：命主辰酉暗合→田宅之祿暗通財帛（賣屋過水）。
巳申暗合→官祿風暴暗灌疾厄（2033健康天條的機制）。

## 六沖（對宮相沖）
```
子午、丑未、寅申、卯酉、辰戌、巳亥
```
釋義：對宮能量正面衝擊。例：2030丑未沖，天相忌沖命宮。

## 四馬地 / 四敗地 / 四庫地
- **四馬地（寅申巳亥）**：驛馬，主動、遷移、變化、奔波。
- **四敗地/桃花地（子午卯酉）**：主情感、變動、桃花。
- **四庫地/四墓（辰戌丑未）**：主收藏、穩定、庫。
命主身宮在巳（四馬地）＋天相忌繫遷移→「動於紙不動於身，動能洩於簽字」。

## 疊宮（R-疊宮先行 · S04）
大限/流年的十二宮，疊在本命十二宮上。
**判讀順序：大限疊宮先定「十年之形」，流年再定座標。順序不可反。**
大限宮位求法：**大運命宮起、全盤輪佈**（禁止在本命盤上數三合——歷史錯誤來源）。

## 宮位轉換法（R-宮位轉換 · S11）
親屬定位以宮推宮：
- 舅 = 母之兄弟宮。母借兄弟宮立命，其兄弟宮 = 命主夫妻宮。
  → 舅舅之事與命主婚姻共用一宮（驗：太太由舅舅介紹，V08）。
- 岳家 = 妻之父母宮 = 夫妻宮的父母位。
- 與手足共有之產 = 兄弟宮之田宅位（命主案例落酉，武殺地空→主分割變現）。

轉換所得之宮與本盤宮位重合時，兩事同論。
