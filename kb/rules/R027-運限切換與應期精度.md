# R027 · 運限切換與應期精度

## 一、核心立場：運限切換沒有精準的分界點
> **本門明訂：「運限的切換時間點，沒有辦法做出很精準的區分點。
> 要看前後宮位、星曜的強勢度，來決定切換的時機點。」**

- 大限、流年之交替**不是**在某一瞬間乾淨切換，而是**漸變、重疊**。
- 判切換時機要看：**前後兩宮的宮位性質** ＋ **各自星曜的強勢度**（強者提前接管、弱者延後交棒）。

### ⭐ 與引擎既有實務完全吻合
別冊《房產史》章結論已寫：「**年份精度依誤差經驗放寬為窗口制**」；
S06 亦定「大運圈定範圍、流年精準定位——瞄準鏡不能當望遠鏡」。
→ 本條是那套「窗口制」的**教義層依據**：不是我們的規則不夠準，
  而是**本門認為運限本來就沒有硬邊界**。F02（丁戊節拍器拆除）之教訓亦同源。

## 二、年內細分：一年切五等份
實務上把一整年切成五個節點：
```
春節過後 → 端午 → 中秋 → 重陽 → 除夕
```
> 用途：當需要比「某年」更細的定位時，以此五節點劃分年內區段。
> 這是本門對「年內擇時」的操作粒度——**比月更粗、比年更細**。

## 三、⭐ 星曜個別延遲：太陰的 20–30% 落後
> **「太陰星進運限時，會晚 20–30% 的時間進大限。也會延遲離開。」**

| 面向 | 影響 |
|------|------|
| **進入** | 太陰的作用**比大限起點晚 20–30%** 才顯現 |
| **離開** | 同樣**延遲退場**，尾巴會拖到下一個運限 |

**推論（本檔補充，待驗）**：以十年大限計，20–30% ≈ **2–3 年**的位移。
故凡以太陰為主訊號的應期，**窗口應整體後移約 2–3 年**，且**前後緣都要放寬**。

### 對命主既有推論的影響（重要，須重審）
- 命主**太陰化科在辰宮（田宅）**；辰屬**太陰落陷位**（寅卯辰巳午未）。
- 別冊 C 表列「**2035 太陰忌＝名分懸置警戒**（V11 參數之前瞻首用）」。
  → 依本條，**該應期窗口宜後移並放寬**（例如由「2035」改為「2035–2038 窗口，
    且尾巴可能更長」），而非釘死單一年份。
- V10「2015 乙未太陰忌入辰＝田線斷象」原判「**中帶誤差**」（實際換屋期 2013–16，忌年居中）
  → **本條可能正是那個誤差的成因**：太陰訊號本來就會前後拖。
  **建議把 V10 的誤差重新解釋為「太陰延遲」的首個佐證，並回測是否成立。**

> ⚠ 這是**新規則回頭修正舊推論**的案例，須依 S09 謹慎處理：
> 單一案例（V10）不足以立通則，但本條有教材依據，屬「教義＋單案吻合」，
> 仍待第二筆獨立事實。

## 四、操作規則
| # | 情境 | 做法 |
|---|------|------|
| P1 | 給大限應期 | 給**十年範圍**，不釘年（S06 大運圈定）|
| P2 | 給流年應期 | 給**窗口**（前後各放寬），不釘單年 |
| P3 | 訊號主星為**太陰** | 窗口**整體後移 20–30%**，且前後緣再放寬 |
| P4 | 需年內定位 | 用五等份節點（春節後／端午／中秋／重陽／除夕）|
| P5 | 運限交界期 | 比較前後宮位性質與星曜強勢度，判斷實際接管時點 |

## 五、延伸禁區
- ❌ 把大限起訖年當作硬邊界（本門明言沒有精準分界點）。
- ❌ 用流年化曜當節拍器釘年份（**F02 已證偽**：流年化曜每十年必重複、無鑑別力）。
- ❌ 太陰主導之事仍釘正年（P3：必然偏晚）。
- ❌ 反過來用「反正有誤差」來事後合理化任何落空——
  **窗口寬度必須在開獎前寫死**（別冊 S15：判定規則須於開獎前寫死）。

## 六、待驗
- **P3（太陰延遲 20–30%）是本條最可驗的一項**：
  拿命主所有以太陰為主訊號的已知事件（V10 2015、V11 2013–16 租屋期、
  2001 天喜會太陰＝太太登場）逐一檢查，實際發生是否**系統性晚於**理論年。
  若三例皆偏晚 → 可升格；若方向不一致 → 證偽。
- 「五等份」與「切換點看星曜強勢度」暫無可驗案例，列存參。
