# R020 · 安祿羊陀法

> **屬「象·第一層機械層」**：確定、可程式化。排盤程式應自動產生，**AI 禁止手算**（鐵律 1/S13）。
> 本檔記錄「規則本身」，供程式實作與查核用。

## 規則：祿存位由「哪個干」決定，四盤不同
| 盤 | 取干來源 |
|----|---------|
| **本命** | **出生年**的天干 |
| **大限** | **大限命宮的宮干** |
| **小限** | **小限命宮的宮干** |
| **流年** | **當年（農民曆）**的天干 |

→ 由該天干查「安祿存星表」得祿存所在宮位。

## 規則：羊陀夾祿（固定關係）
```
擎羊 = 祿存的「順時針一格」
陀羅 = 祿存的「逆時針一格」
```
即祿存居中，羊陀分居前後一位（羊陀夾祿）。定了祿存，羊陀自動確定。

## 與既有規則的接口（重要）
- **接 `R018` 空宮借對宮法**：R018 說「空宮內若有**運限盤產生的擎羊、陀羅**則不能借」。
  本條正是那些運限羊陀的**產生方式**——大限用大限命宮干、小限用小限命宮干、流年用當年干。
  兩條合起來，空宮借與不借才算完整可判。
- **接 `R019`**：四盤分工既定，各盤自帶一組祿羊陀，故同一宮在不同盤可能「能借/不能借」不同。
- 祿存亦是「財庫成立」的關鍵（見 `STAR-天府`：財庫要有祿才算財庫，祿存優於化祿）。
