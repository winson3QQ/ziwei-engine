# R031 · 疊宮法（看事件背後的原因）

## 一、疊宮是什麼
- 宮位代表**時空環境**；**疊宮＝時空環境的綜合考量**。
- 不同盤（本命／大限／小限／流年）的宮位互相重疊時，會產生相互影響。

**核心比喻：地基與建築物**
| 層 | 角色 | 時間跨度 | 影響力 |
|----|------|---------|--------|
| **本命**（最底層）| **地基**：基礎條件 | 一生 | **最大** |
| **大限**（中層）| 中段結構 | 十年 | 中 |
| **小限／流年**（最上層）| **建築物表面**：表現出來的現象 | 一年 | 現象最明顯 |

> **盤層越下面，時間越長，影響力越大。**
> 同一棟建築蓋在不同地基上，結果完全不同。

## ⭐ 二、標準操作：由上而下找因，由下而上敘事
```
步驟1  在【上層盤】確認現象
        例：小限財帛宮有擎羊 → 破財

步驟2  層層往下疊，找原因
        小限財帛宮 疊到 大限的哪一宮？  → 中層原因
        大限該宮   再疊 本命的哪一宮？  → 根本原因

步驟3  【從下往上】敘述因果鏈
```

**完整範例（大耕）**：
```
小限財帛宮（破財現象）
   ↓ 疊
大限夫妻宮（感情問題）
   ↓ 疊
本命官祿宮（工作層面）

因果路徑：工作(本命官祿) → 感情波動(大限夫妻) → 破財(小限財帛)
```

## ⭐ 三、進階：把疊宮當作「篩選」（疊宮二）
> **一個宮位通常有 6 種以上含義；疊三層盤時會產生 6³ 種變化。**
> 所以疊宮的實質是**逐層排除不適用的意義**，而非疊加更多意義。

| 步驟 | 動作 |
|------|------|
| 1 | **識別主要現象**（觀察上層盤該宮的星曜與化曜）|
| 2 | **逐層疊合**（先疊大限，再疊本命）|
| 3 | ⭐ **刪選意義**——依疊合結果**排除不適用**的宮位含義 |
| 4 | **組織解釋**——把篩選後剩下的含義組成一個完整故事 |

〔大耕〕此技法**需要「聯想能力」與「組織能力」**。
**範例**：流年遷移宮太陽化祿 → 疊大限官祿宮 → 再疊本命僕役宮
→ 解為「**因工作需要出國，而機會源自交友圈的關係**」。

> 引擎接口：這正是本引擎「**掛卦＝attention**」的操作版——
> 象是一團疊加的潛義（6 種以上），**疊宮就是用時空脈絡把不相干的義刪掉**。
> `META-核心機制` 二節的類比在此得到本門的技術實作。

## 四、重疊宮位的基本影響
> 〔大耕〕**「重疊的宮位，會是對於你影響最大的宮位。」**

| 重疊 | 意義 |
|------|------|
| **身宮 ＋ 財帛宮** | 一生與金錢緊密相關（愛花或愛存，都是對財務的執著）|
| **大限命宮 ＋ 本命夫妻宮** | 這十年的個性與價值觀，**受感情議題深刻影響** |
| **大限命宮 ＋ 本命官祿宮** | 這十年最在乎工作（並須同時看大限官祿宮，見 SOP 步驟5）|

**至於「怎麼重視、怎麼追求」** → 由**該宮三方四正內的星曜**決定。
（＝疊宮定「主題」，星曜定「方式」。）

## 五、硬限制（承 META-解盤SOP）
```
最多疊 3 張盤，且不可跳層
✅ 本命 → 大限 → 流年 ／ 本命 → 大限 → 小限
❌ 本命 → 流年 → 流月（跳過大限）
```

## 六、與引擎既有規格的關係
- **S04／R-疊宮先行**：「大限疊宮先定十年之形，流年再定座標，順序不可反」——
  本條提供其**完整技法**（不只先後，還有由上找因、由下敘事、篩選法）。
- **鐵律 4 多層收斂**：疊宮是三層收斂中的一層（另有飛化、暗合）。
- **`R019`**：小限＝內因、流年＝外因；疊宮追因時須標明該層是內因或外因。

## 七、延伸禁區
- ❌ 只在單一盤上解釋現象而不往下追因（會得到「發生了什麼」卻說不出「為什麼」）。
- ❌ 疊超過 3 層或跳層。
- ❌ 把疊宮當「意義相加」——**它是篩選、是刪去法**。
- ❌ 疊出因果鏈後仍不看該宮三方四正的星曜（主題有了，方式沒有）。

## 八、待驗
- **可驗設計**：拿別冊已驗事件（如 2013 賣＋買、2004 完婚、2026 昇等），
  用本法從小限/流年層往下疊，檢查推出的「根本原因」是否與命主實際經歷相符。
- 這是少數能檢驗「**解釋力**」而非「命中率」的規則——
  評分標準應為：因果鏈是否與命主自述的實際成因一致（由命主判定）。
