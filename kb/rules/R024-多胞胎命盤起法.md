# R024 · 多胞胎命盤起法

## 規則：同時辰、不同起宮
同時辰出生的多胞胎共用一張時辰盤，但**各自以不同宮位當命宮**重起十二宮。

| 排行 | 以該時辰盤的哪一宮當命宮 |
|------|------------------------|
| **雙胞胎** | 兄／姐 → **命宮**；弟／妹 → **遷移宮** |
| **四胞胎** | 老大 → **命宮**；老二 → **遷移宮**；老三 → **兄弟宮**；老四 → **僕役宮** |

### 結構觀察（本檔補充）
四個起宮恰為**兩組對宮**：命─遷、兄弟─僕役。
兩組皆為「自我 ↔ 他人」軸（命遷＝我與外境；兄僕＝平輩近親與泛交），
排序上先用命遷、再用兄僕。此結構規律可供程式實作時檢核。

## 排行的認定
- 台灣法律：**先出生者為兄/姐，後出生者為弟/妹**。
- ⚠ **須依命主的文化背景為依據**——部分文化以後出生者為長。
  定盤前先確認當事人所屬文化的認定方式，**否則整張盤起錯**。

## 雙胞胎的一般現象（觀察層，非規則）
- 小時候長相差不多、家世背景差不多。
- **越長大長相越不像、個性差越多。**
> 這正是「不同起宮」的現實對應：同環境（家世）但不同命盤 → 隨時間分化。
> 屬本門對此起法的合理性說明，**非可驗規則**，存參。

## 適用邊界 / 待驗
- 命主家中若無多胞胎案例，本條**無從以自家盤驗證**，須待外部樣本（S09）。
- 屬機械起盤層，應寫入排盤程式：輸入排行 → 自動切換起宮。
