# R024 · 多胞胎命盤起法

## 規則：同時辰、不同起宮
同時辰出生的多胞胎共用一張時辰盤，但**各自以不同宮位當命宮**重起十二宮。

| 排行 | 以該時辰盤的哪一宮當命宮 |
|------|------------------------|
| **雙胞胎** | 兄／姐 → **命宮**；弟／妹 → **遷移宮** |
| **四胞胎** | 老大 → **命宮**；老二 → **遷移宮**；老三 → **兄弟宮**；老四 → **僕役宮** |

### 結構觀察（本檔補充）
四個起宮恰為**兩組對宮**：命─遷、兄弟─僕役。
兩組皆為「自我 ↔ 他人」軸（命遷＝我與外境；兄僕＝平輩近親與泛交），
排序上先用命遷、再用兄僕。此結構規律可供程式實作時檢核。

## 排行的認定
- 台灣法律：**先出生者為兄/姐，後出生者為弟/妹**。
- ⚠ **須依命主的文化背景為依據**——部分文化以後出生者為長。
  定盤前先確認當事人所屬文化的認定方式，**否則整張盤起錯**。

## ⭐ 反推題：主星「實坐」在誰的命宮？（作業08 Q18）

雙胞胎的兩個命宮**互為對宮**（命─遷）。若該組主星是**同宮型**（如同陰只在子午、
機梁只在辰戌），必然是**一人的命宮有主星、另一人的命宮是空宮借對宮**。
**由題目線索反推時，必須決定星實坐哪一邊。**

**判準（作業08 標準答案反推，寫死）**：
> **特質描述最強烈、最具體的那一個人，主星「實坐」其命宮；另一人為空宮借對宮。**

**作業08 實例**：題目對阿妙（妹）的描述最重（好人緣、溫柔、不受道德侷限、周旋多位男士
＝「最強小三」＝**太陰落陷**），阿虎只有背景描述。
→ **標準答案：太陰天同實坐「午」（阿妙命宮）、「子」為空宮（阿虎命宮借對宮）。**

⚠ **本引擎在此答反了**：我推「同陰實坐子（阿虎）、阿妙在午借過去呈落陷態」——
**地支分配（兄子妹午）對，星的實坐位置錯。**
教訓：**空宮是「借來的」，特質必然較淡；題目寫得最濃的那個人，星就在他宮裡。**

## 雙胞胎的一般現象（觀察層，非規則）
- 小時候長相差不多、家世背景差不多。
- **越長大長相越不像、個性差越多。**
> 這正是「不同起宮」的現實對應：同環境（家世）但不同命盤 → 隨時間分化。
> 屬本門對此起法的合理性說明，**非可驗規則**，存參。

## 適用邊界 / 待驗
- 命主家中若無多胞胎案例，本條**無從以自家盤驗證**，須待外部樣本（S09）。
- 屬機械起盤層，應寫入排盤程式：輸入排行 → 自動切換起宮。
