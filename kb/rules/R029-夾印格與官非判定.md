# R029 · 夾印格與官非判定

## 零、先講操作態度（教材明訓）
> **「不要執著『官非』這兩個字。在無法區分細膩度前，只需先理解『這有官非的跡象』就好。」**
> 且每個星曜的解釋需**對應宮位**，並**對應是哪一張盤**（本命／大限／流年）。

→ 判官非分兩階：**先判「有沒有跡象」**（粗），**再判「是什麼樣的官非」**（細）。
  細度不足時就停在粗判，**不要硬掰細節**。（呼應「條件未用盡不下判斷」。）

## 一、刑忌夾印格
```
刑 = 擎羊 或 天刑
忌 = 化忌
印 = 天相
```
**成立形態**：
1. **天相化忌，帶擎羊或天刑。**
2. **對宮化忌也算。**
3. 若忌**從三方四正過來** → ⚠ **須留意是從哪一個宮位過來，那對他的影響是什麼**。

**象**：基本上就是**犯官非**（可能賠錢，或直接是法律上的糾紛）。
⚠ **但官非的大小與嚴重性，仍需從其它宮位組合判斷**——不可只憑成格就斷嚴重度。

## 二、蔭祿夾印格
```
蔭 = 天梁
祿 = 化祿 或 祿存
印 = 天相
```
**成立形態**：天相被**天梁與巨門所夾**，且**天梁帶祿（或祿存）**，**或巨門帶祿（或祿存）**。

**範例**：
| 天相所在 | 天梁帶祿 | 巨門帶祿 |
|---------|---------|---------|
| **命宮** | 父母宮天梁帶祿 → **爸爸會給資源或給錢** | 巨門帶祿 → **媽媽會給很多關心與關懷** |
| **財帛宮** | 子女宮天梁帶祿 → **家中會給資源或錢** | 疾厄宮巨門帶祿 → 運限上表示**生活過得還不錯** |

〔大耕〕蔭祿夾印通常指向**一生財務安穩**（本命與運限盤皆適用）。

## ⭐ 三、兩格「同時存在」（本條最重要的洞見）
> **刑忌夾印與蔭祿夾印，基本上是同時存在於「天相＋天梁」這個組合內。**

因為兩格共用同一批星（天相被天梁、巨門夾），**只是看當期補進來的是「祿」還是「刑忌」**。
故兩者**不是互斥的吉凶二選一，而是可以疊加的兩條線**：

| 情境 | 讀法 |
|------|------|
| 刑忌夾印的大限中，**出現蔭祿夾印** | 我在出問題時（犯官非／賠錢），**卻有一個來自老天的幫忙**（如意外有錢），**減緩了那個災害** |
| 大限處於蔭祿夾印，**運限轉換走到刑忌夾印**（如祿存放巨門或擎羊放天相，再補一個忌）| **我賺很多錢，但突然犯官非** |

> ⭐ 引擎接口：這是**「吉凶同時成立」**的明確教義依據——
> 輸出時不可把該期壓縮成單一吉或凶，**必須兩條線並陳**。
> 與 `META-派系基礎`「不能用太單一的邏輯」、「中性論」同源。

## 四、官非的另一條判準（父疾線）
> **巨門／太陽／天府／廉貞／破軍**，這五顆星在**運限的父疾線**上**逢煞忌**，
> 對應盤上的狀況**可視為官非**。

- 父疾線＝父母宮 ↔ 疾厄宮（對宮）。父母宮主**公門、文書**（見 `PALACE-父母`）——
  故此線逢煞忌即指向文書／公門之事出狀況。
- 這條與「天相／文昌」那條是**兩套獨立的官非判準**，可互相參證。

## 五、天相與文昌的官非之分（承批次09）
| | 管什麼 | 逢忌 |
|---|---|---|
| **天相**（主星）| **秩序**——人與人的約定。**秩序大於規則** | 不會有情緒問題 |
| **文昌**（輔星）| **規則**——筆墨文書；**背後真正指的是「你的思慮」** | 思慮出問題 → **易有情緒上的問題** |

**補充（批次10）**：
- **天相在雙星組合中都是輔佐前面那顆星**，讓前面那顆較有規範、較有秩序。
- 天相逢煞忌時，秩序與規範會**不照一般世俗邏輯走**；
  ⭐ **但對天相本人而言，他仍然是在規範他的秩序，只是「你覺得他不是」而已。**
  （比批次09「自己不會覺得」更精確：不是無自覺，是**自有一套標準**。）
- ⚠ **特別留意「天相＋武曲」的組合**：運限盤若碰煞忌，
  **容易和人因為錢財而產生合約上的糾紛**（例：約好一起投資卻放鴿子、錢沒匯過來）。

## 七、延伸禁區
- ❌ 成格即斷嚴重度——**大小與嚴重性須從其它宮位組合判斷**。
- ❌ 把官非讀成必然打官司（見 `REF-名詞釋義`：官非＝約定的事被更動）。
- ❌ 只取刑忌夾印而不查蔭祿夾印——**兩格同時存在，漏查就會把有緩衝的年判成純凶**。
- ❌ 忌從三方四正過來卻不問來源宮位。
