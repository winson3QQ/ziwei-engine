# R018 · 空宮借對宮法

## 空宮的定義（防誤讀 · 作業01 Q2 誘答正打此處）
> **空宮＝該宮內沒有「十四主星」的任何一顆。**
> ⚠ **空宮不等於「整個宮位什麼星都沒有」**——
> 空宮裡**可以有輔星、煞星、雜曜**（正因如此，才有下方「有四煞昌曲則不能借」的規則）。

## 規則（本門）
宮內**無十四主星**者為「空宮」。空宮判讀時**直接借對宮**：
- 可借對宮的**十四主星及其四化**。
- 被借星曜的力量**保持不變**（借來仍是原力，不打折）。

## 例外與阻斷條件（關鍵，缺一必錯）
1. **太陽星、太陰星例外**：借這兩顆時力量另有說明（老師課堂補述，待補細則）。
   → 暫記：借到日/月時，先掛「待補例外規則」旗標，不逕自等同其他主星。
2. **本宮若有下列六星，則「不能借」對宮**：
   四煞（擎羊、陀羅、火星、鈴星）＋ 昌曲（文昌、文曲）——共六顆。
   有其一即不借，該宮以現有煞/昌曲之象自論。
3. **運限盤產生的擎羊、陀羅**：需檢查空宮內是否被運限盤帶進羊/陀；
   有的話**同樣不能借**（此為動態阻斷，隨大限/流年變動）。

## 判讀流程（掛進解盤 SOP）
```
空宮？ ──否──> 照本宮主星論
   │是
   ├ 本宮有 四煞/昌曲（本命或運限帶入）？ ──是──> 不借，以煞/昌曲象自論
   │                                        └否
   ├ 對宮主星是太陽/太陰？ ──是──> 借但掛「日月例外」旗（待補細則）
   │                        └否
   └ 借對宮十四主星及其四化，力量保持
```

## 與引擎既有結構的接口
- 屬「象·第一層機械層」（`META-核心機制` 一），確定、可程式化。
  未來排盤程式應自動判定空宮借與不借，AI 不手動裁。
- 運限羊陀的動態阻斷，與 `R-疊宮先行`（大限/流年疊宮）同一時序層處理。

## 適用邊界 / 待補
- 太陽、太陰的借宮例外細則**尚缺**——命主教到時補進本檔，勿自行臆造。
- 本條屬本門教義，機械規則性強、爭議低，但仍待命主真盤（有空宮者）實例對照一次。
