# 進階班 第10~11堂（逐字歸檔·壓縮）

## 第10堂 · 空劫星
**前言**：複習很重要；改運＝在能更動的事情中一點一滴改變讓狀況好轉；命理教的是思考邏輯與看懂自己的條件、分析即將面臨的狀況，**不是固定答案**；⚠ **紫微斗數無法看出生雙胞胎，坊間說法現今看都不準**。

**空劫總則**：空劫用得好人生沒煩惱；**空劫有時間性**（大限有空劫事情還是會發生；流月可能馬上空）。
1. 清末民初前空劫＝「天空」與「地劫」；後整併神煞多出天空星，遂改為今之「**地空**」與「**地劫**」。
2. 「空」如「化忌」常被認為不好，但星曜**客觀中性無好壞**；被認為不好因：①覺得空就是不對 ②有時像失去了什麼而不開心，**但擋掉災的機率更大**。
3. ⭐ **空劫屬宮位體系：會「空掉宮位」，讓宮內星曜沒有環境發揮其力量，但空劫「不影響星曜」本身。**
   - 比喻：荒島上的法拉利（車庫一開是大海）／米其林主廚但餐廳限水電瓦斯無法開業／挖來財務長卻只給山洞無電腦網路（反之若挖到只會A錢的財務長，同樣沒環境做壞事）。
4. **地空＝本來會擁有但卻沒有；地劫＝本來會擁有但被別人拿走。** 例：朋友答應的案子轉給別人＝地空；案子簽好卻被更低價搶走＝地劫。

**本命盤**：仍是對「宮位」造成影響（沒環境讓星曜特質完全發揮）。地空地劫同坐命，因力量一直沒環境發揮，最後可能有「一無所有」感——但**非絕對**，是本命時間區段長讓人有「事情一直沒對應舞台」的感覺，若直接解讀為空劫影響星曜＝**倒果為因**。
- **空劫同宮·巳亥**：環境讓他覺得不能做/沒機會/何必如此→**有態度有能力但沒環境**。坐命兩種特質：①頭腦空空、沒主見/沒想法 ②很多想法創意（大幅受對宮及三合影響）。例：紫微七殺＋空劫/天府落命或財帛→仍有創業想法但覺環境不給；太陽＋空劫/巨門→仍侃侃而談政治社會但不競選，遷移看仍覺他有能力。
- **空劫對拱·寅申**：兩宮都不佳，大幅受三合影響。
- **空劫·卯未 或 丑酉**：兩宮星曜力量發揮不出，影響被拱的宮。
- **空劫·辰午 或 子戌**：兩宮力量發揮不出，但彼此不在三方四正，**影響最小**，所夾宮位受影響也小。

**運限盤**（空劫同宮或對拱，**終將一無所有**）：重點在「終將」——中間仍有過程，看討論哪張盤/宮內星曜/事件。例：大限夫妻桃花＋空劫＝交往八年最後分手；流年＝曖昧幾月不了了之；流月＝吃幾次飯發現不適合。「終將」以大限＝最後一兩年、流年＝最後兩三月，**依事件時間長短判斷合適與否，非什麼都不能做**；逢空劫也可能是**吵架/官司/疾病結束**（好事）。**宮位沒被引動，空劫影響較不明顯。**

## 第11堂 · 福德宮
**高手看福德**：能否渡過災難看福氣、運氣、精神潛意識狀態。
**核心**：來財方式、錢的由來、晚年、精神、福氣、運氣。
**晚年**：a.通常死前十年 b.概念與身宮雷同，指最後不用工作/退休的時間 c.心靈深處追求的生活，最後時光往該方向追求 d.很早財富自由則福德影響提前。
**祖父（實質影響力）**：父母宮的父母宮＝祖父；家世背景。
**祖父已不在→祖墳**：a.福德宮的田宅宮＝僕役宮＝祖墳宮位 b.家中很多沒來由/解釋不出的棘手狀況可能來自風水，祖墳亦屬風水，滿足實質影響力看僕役宮 c.探祖墳風水看運限 d.**只談土葬** e.**只適用長孫（實質影響力）** f.祖墳出問題影響你的條件：先確認家族有土葬先人＋運限福德宮化忌進子/田/命，或僕役宮化忌進子/田/命 g.祖墳選址看僕役宮：運限僕役宮宮干化祿/祿存的位置、該位置煞忌不能多、且該位置能葬人。
**財帛vs福德差異**：財帛＝適合做什麼賺錢；福德＝老天爺給的賺錢機會。
**本命vs運限福德**：本命＝「適合做什麼賺錢」的天賦能力；運限＝當前運限機會在哪方面。
**精神狀態**：精神狀態與運氣相關、賺錢多少需運氣→財福一線。福德談：有無好（適合）的靈魂/精神狀態、有無受庇佑的好決策（四化、祿羊陀會影響決策）。
- **倒霉能否過關看福德**：a.不能遇超過兩個煞忌 b.強旺/好掌權星入本命福德→偏勞碌、無法享受軟爛 c.遇困難「轉念」是轉運關鍵（安逸溫和星天同/太陰/天梁易釋懷；強勢好掌權星難放開；如生意失敗/感情出問題能否轉念站起） d.有時強悍星在福德是好的（需強悍意志的場合：高風險手術、重病加護、撐到後面好時機） e.有無祿/權（同宮對拱強）＝能否掌握靈魂精神撐過關卡 f.本命/大限/小限/流年都要看 g.有時好壞難說（嚴重車禍生還但頸下癱瘓）。
**靈魂學**：宗教載體為文化、詮釋因文化而異；宗教有政治/權力目的需理性看；交叉比對可見共同真相；共識＝肉體為靈魂所控制（佛教「肉身寶船」）；許多宗教根本教義在教人**不受情緒影響**——煞星勾動基本情緒，故解盤邏輯亦教人**控制情緒、保持客觀，把煞星為己所用**。斗數課程不深探靈魂學。
