# 助教筆記 07（逐字歸檔）

## 天梁星雙星組合

### 1. 同梁對拱（巳亥位）
**天同星坐命**
- 比較懶散。在外看起來好像懂得很多（遷移宮為天梁）。
  天同幫助別人的時候，如果別人不願意接受，那就算了。
- 遇到變動，可以隨遇而安。

**天梁星坐命**
- 在外看起來不在乎，也跟大家很好（遷移宮為天同）。
  天梁庇蔭星，覺得我做這些事情都是為了你好，也會希望你聽我的話。
  因為有些價值是相信或者遵守的，天梁就會覺得不應該這樣做。
- 因為想要幫助別人，願意探索，想要懂更多東西，也可以接受生活有所變動。

**四化對於同梁巳亥位命主的影響，為什麼會增加變動的機會、會想要往外走？**
- 因為天同天梁容易帶祿權科，**在遷移宮上面有四化，因為四化的引動**，
  命主可以讓生命變得更精彩。

### 2. 同梁同宮（寅申位）
星曜特質：
- 看起來像小孩，**內心有很深沉成熟的一面**。
- 無論對宮是否空宮。看起來是好揪、胸無大志的樣子，但還是有很成熟的一面。
- **兩大福德主同宮，代表遇難呈祥，可以逢凶化吉。但也是要遇難，才會呈祥，
  只會出現在運限盤。**
- ＃觀念釐清：為什麼古人知道這個人運氣很好？**因為遇到很衰的事情，居然死不了。**

### 3-6.
陽梁對拱（子午）／陽梁同宮（卯酉）→ 太陽星時補充。
機梁對拱（丑未）／機梁同宮（辰戌）→ 天機星已講述。

## 太陽星

1. 星曜特質：**化氣為貴、五行屬陽火、官祿主**。**爸爸的概念，喜照不喜坐**。
   坐命宮有**刑剋父親**，女命坐命宮亦有**剋夫、剋子**的概念。
2. 太陽坐命**喜居高位**，重視社會價值、議題，關心社會經濟、局勢。**博愛，有號召力**。
3. 外表長相：
   - 男：大眼，眼睛圓且明亮；**太陽在旺位者皮膚偏黑，落陷者皮膚偏白**；
     身材高挑（台灣標準約 180 公分以上）。
   - 女：大眼，眼睛圓且明亮；**太陽在旺位者皮膚偏白，落陷者皮膚偏黑**；
     身材高挑（台灣標準約 162 公分以上）（對宮巨門、或巨日同宮、日月同宮）；胸部較大。
   - 兩者臉部都偏圓，**體重容易起伏**，而有體型胖瘦反覆發生的情況，但多半身材屬於胖的狀態。
4. 生活習慣：**落陷的太陽，比較喜歡在晚上生活**。
5. 太陽是**需要在意旺落**的星曜
   - **旺位：寅卯辰巳午未**
   - **落陷位：申酉戌亥子丑**
   - 至於**太陽旺落程度與星曜好壞沒有直接關係**，需要靠周遭環境是否適合這顆太陽星而定。
   - **落陷的太陽**，有自己認為的規則，**願意去接受灰色地帶社會價值**，
     甚至於跟別人的價值觀會有所不同。
   - **在意太陽旺落的星曜有二：太陰與巨門。**
6. **天機星坐命時，夫妻宮為太陽。**
7. **太陽星坐命時，夫妻宮為天同。**

### 8. 太陽雙星組合
**陽梁對拱（子午位）**
- **日麗中天格**：太陽在午，天梁在子。
  - 太陽位於旺位，如果坐命宮，會十二宮都像太陽，在外又像天梁一樣，
    喜歡幫助別人、努力為別人付出等等。
  - **古書寫超好，但勞碌命，很累。最好命坐天梁，太陽在午，比較不會那麼辛苦。**
- 命坐太陽在子，遷移天梁在午
  - **俗稱「阿信命格」**，做牛做馬的人。落陷的太陽，仍然做得很辛苦，
    很想要幫助別人、制定秩序等等，但可能因為**領袖魅力不足**，
    比較無法取得大家的信任跟追隨。
- **太陽為什麼喜照不喜坐**：只要看起來很像要關心社會（遷移宮放太陽）就好了，免得很累。

**陽梁同宮組合（卯酉位）**
- 關心社會，**適合發展醫療、NGO 組織、基金會**。因為希望社會照我的秩序去走，
  對宮空宮，借對宮表裡如一。
- **陽梁昌祿格**：幾乎是太陽最好的格局。太陽天梁，與**文昌**同宮或者對宮，有很好的思路，
  加上**化祿或祿存**。在三方四正內也算，但**不是正格**。命主愛唸書、博學，喜歡幫助人。
- **日照雷門格**：就是陽梁同宮在卯酉位。

其餘：日月對拱（辰戌）／日月同宮（丑未）→ 太陰星時補充；
巨日對拱（巳亥）／巨日同宮（寅申）→ 巨門星時補充。

## 太陰星

1. **化氣為富、五行屬陰水、田宅主**。**媽媽的概念，守護家庭**。
   心思細膩，**仍然規矩存在，不可以隨意冒犯**。細心、溫柔、慢條斯理、**要求別人動作要快**。
2. **財星之一，也屬庇蔭星。**
3. 長相：
   - 男：花美男，屁股翹。**旺位皮膚偏白**，太陰是細瓜子臉。
     日月的長相都是眼睛靈活，**太陰眼睛比較細長**，身上易有小細毛。
   - 女：眼睛靈活有神、偏丹鳳眼，圓額瓜子臉、有美人尖，嬌小、斜肩，上半身瘦、屁股大，
     中年後法令紋較長，有女人味。**旺位皮膚偏黑**。
     ⇒ **旺位女生偏黑，落陷女生偏白。**
4. 旺位落陷位
   - **旺位：申酉戌亥子丑**
   - **落陷位：寅卯辰巳午未**
   - **太陰星的亮度，是隨著太陽而變化。**
5. **太陰星進運限時，會晚 20–30% 的時間進大限。也會延遲離開。**
6. 太陰星也有**享受享樂**的概念，很容易花在吃喝玩樂上頭。
7. 太陰星也是**桃花星**，緣自於因為他溫柔細心體貼。
8. 太陽太陰星遇到**三吉加會**
   - 三吉加會，代表三方四正內有祿權科，**而且要擺在正確的宮位上**
     → **正式的擺法應該是化科在命宮，化權在官祿宮，化祿在財帛宮。**
   - **落陷太陽星**遇三吉加會，容易有**打腫臉充胖子**的狀態。
   - **落陷的太陰**，遇到三吉加會，**偷偷賺大錢**。
9. **日月同宮，若可借對宮時，日月的旺亮度，記得由對宮的地支來決定。**

## 斗數盤上時間的交換概念
- **運限的切換時間點，沒有辦法做出很精準的區分點。
  要看前後宮位、星曜的強勢度，來決定切換的時機點。**
- 實務上用法**將一整年切成五個等份**
  → **春節過後、端午、中秋、重陽、除夕**
