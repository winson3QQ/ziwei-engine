# 四煞總論（火鈴羊陀）

> 這是煞星的**框架先行檔**。等命主餵到各煞星細部，再拆成四顆星的四層區塊。

## 本門定義
- **四煞 = 火星、鈴星、擎羊、陀羅**。
- 代表人因**欲望**衍生的情緒、企圖等，各自四種不同的**破壞力量**。
- **煞星破壞宮位，同時也破壞星曜**（雙重破壞：既損宮位機能，也損同宮主星）。
- **空宮獨坐煞星**：單純視為煞、損害該宮位（無主星可破，就純破宮）。

## 四煞象徵（老師文章對應，細節待建）
| 煞星 | 象 | 待建檔 |
|------|-----|--------|
| 火星 | 一把火（熱情、衝動、爆發力） | STAR-火星 ⬜ |
| 鈴星 | 小刀（吃苦沉潛、等待時機） | STAR-鈴星 ⬜ |
| 擎羊 | 大刀（一刀斷水、疾如風） | STAR-擎羊 ⬜ |
| 陀羅 | 陀螺（拖磨、業障、擺脫不掉） | STAR-陀羅 ⬜ |

## 本門要點（值得寫死）
1. **煞亦是貴人**：本門明言「是煞忌亦是貴人的羊陀火鈴」——煞非純負，逢對的結構可轉為推力。
   → 這與 CLAUDE.md 錯誤史 S10「輔弼逢煞越幫越忙／真貴看魁鉞」不衝突：
     此處講的是「煞」本身的雙面性，非輔星逢煞。兩條並存，勿混。
2. **煞破宮又破星**：判宮時，同宮主星的力量要打折（破星）；宮位機能也受損（破宮）。
3. **火鈴與貪狼**：火鈴對貪狼是**喜會**（火貪/鈴貪格，見 REF-星曜喜會忌會表），
   是全表少數「煞為喜」的例子——煞的雙面性實例。

## 延伸禁區
- 勿見煞即斷凶。先看：煞落何宮、同宮何星、是否成格（火貪/鈴貪）、是煞破還是煞助。
- 空宮運限盤產生的擎羊/陀羅會**阻斷借對宮**（見 R018），此為機械層規則，勿當吉凶論。
