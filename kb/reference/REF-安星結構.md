# 十四主星安星結構（紫微系 ＋ 天府系）

> ⚠ **用途限定**：本表為**核對與推導**用（例如推雙星組合的地支與對宮）。
> **實際排盤仍一律由程式產生，AI 不手算**（鐵律1／S13）。

## 一、兩系與定位法
十四主星分兩系，各自由一個「頭」star 起算：
- **紫微系（6顆）**：紫微、天機、太陽、武曲、天同、廉貞
- **天府系（8顆）**：天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍

### 紫微系：以紫微為基準「逆行」
| 星 | 相對紫微 |
|----|---------|
| 紫微 | 0 |
| 天機 | **逆 1** |
| 太陽 | **逆 3** |
| 武曲 | **逆 4** |
| 天同 | **逆 5** |
| 廉貞 | **逆 8** |

### 天府系：以天府為基準「順行」
| 星 | 相對天府 |
|----|---------|
| 天府 | 0 |
| 太陰 | **順 1** |
| 貪狼 | **順 2** |
| 巨門 | **順 3** |
| 天相 | **順 4** |
| 天梁 | **順 5** |
| 七殺 | **順 6** |
| 破軍 | **順 10** |

### 紫微與天府的關係
以地支序（子=1、丑=2 … 亥=12）計：
```
紫微位 ＋ 天府位 ≡ 6 (mod 12)
```
→ 兩者對稱於**寅–申軸**；當兩者同位時即 **紫府同宮於寅或申** ✅
