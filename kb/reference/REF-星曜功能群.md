# 星曜功能群（分類查表）

> 本門常以「功能群」歸類星曜。同群之星**功能相近但機制不同**——
> 判讀時要說出**機制差異**，不能只貼群標籤。

## 三福星
| 星 | 福的機制 | 共通限制 |
|----|---------|---------|
| **天府** | **化煞為用**（有頭腦地運用煞星）| **傷害仍然存在** |
| **天同** | **不在乎、不計較**（以樂觀心情面對煞星）| **傷害仍然存在** |
| **天梁** | **降低災害**（唯一能降災者）| **傷害仍在**；**只在運限盤**生效；**煞太多則失效** |

> ⭐ 三福星共通鐵則：**福星不消災，只改變承受方式。**
> 教材對「遇難呈祥」的釐清：古人怎麼知道這人運氣好？**因為遇到很衰的事，居然死不了。**
> ——**福星的證據是「倖存」，不是「沒事」。**

## 三財星
| 星 | 財的性質 |
|----|---------|
| **武曲** | **正財星**（靠勞動、穩定、定期）；⚠ 僅在命/身/財/福才真是財星 |
| **太陰** | **田宅之財**（儲蓄、不動產累積）；單純把錢放著不動 |
| **天府** | **庫星、聚寶盆**；⚠ **要有祿才算財庫**（祿存優於化祿）；儲蓄但**中間要長利息** |

## 五顆博學星（同為博學，動機全然不同）
| 星 | 為何博學 |
|----|---------|
| **天機** | 因**善思考、聰明、有邏輯** → 主動找知識學習 |
| **天梁** | 因**想照顧人**、追求身心靈成長 → 需要多學以具備能力 |
| **天同** | 因**好揪**——人家學什麼我也學什麼，好相處，想認識更多世界 |
| **巨門** | 因**沒安全感**——深怕知道得不夠、怕無法與人對談；**會去學「垃圾知識」**（不一定有用但就是想知道）|
| **貪狼** | 因**慾望**——希望得到很多東西 |

> ⭐ 這張表是「**同象異因**」的最佳範例：五顆星都表現為「學很多」，
> 但動機分別是**理性、利他、從眾、焦慮、慾望**。
> 判讀時若只說「博學」等於沒說——**必須指出是哪一種博學**。
> （同理見 `R025` 固執之辨：紫微為面子、破軍為夢想、七殺為目標。）

## 桃花星（陸續補）
- **貪狼**（正桃花）、**廉貞**（次桃花）、**太陰**（溫柔細心體貼而生）、
  **天同**（人緣）、**紅鸞天喜**、**文曲**、**破軍**（屬水）、**巨門**（屬水）。
> 註：教材提及「屬水的桃花星（天同、貪狼、破軍）」；水性與桃花相關為本門通則。

## 壽星 / 長壽星
- **天機**（三壽星之一）、**天梁**（在命／福／疾時為長壽星）、**天同**。
> 機梁在丑未為「兩壽星同宮」。

## 對星
- **太陽 ↔ 太陰**：〔大耕〕「**太陰與太陽便是為對星**」——月光源自日光，
  **太陽暗則太陰弱**。判太陰必先看太陽。
- **紅鸞 ↔ 天喜**：恆為對宮。
- **擎羊 ↔ 陀羅**：恆夾祿存（見 `R020`）。

## 需在意廟旺落陷的星（唯三）
**太陽、太陰**（本身即是「光」，亮度直接對應星義）＋ **巨門**（其表現由太陽位置決定）。
> 其餘主星**不以廟旺落陷為主判準**——見 `R025`。

## 固定結構對照（同宮/對宮必然關係）
| 條件 | 必然 |
|------|------|
| 紫微在命宮 | 天機必在兄弟宮；財帛宮必為武曲 |
| 天府 | 對宮**一定**是七殺 |
| 太陽坐命 | 夫妻宮為天同 |
| 天機坐命 | 夫妻宮為太陽 |
| 巨門坐命 | 福德宮必為天梁 |
| 天機巨門在命宮 | 福德宮必為天梁（機巨對拱時財帛宮為天梁）|
| 破軍 | 對宮必為天相 |
| 武府坐命 | 夫妻宮必破軍、遷移必七殺 |
| 紫府 | 在寅、申位同宮 |

> 這些是**機械層的必然**（第一層），可直接用於定盤與交叉檢核，無需驗證。
