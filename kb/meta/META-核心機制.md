# 核心機制：這個引擎如何運作、如何長大

本檔是整個引擎的世界觀。所有規則都在它底下運作。第一次接手本專案，先讀這份。

---

## 一、三層結構：象 → 字義 → 人生

解盤是把「二維盤面的象」翻譯成「命主的立體人生」。分三層：

- **第一層 · 機械層（象）**：排盤、安星、四化落宮、三方四正、疊宮、暗合、四馬地。
  確定、可程式化、無詮釋空間。**交給程式，AI 不碰。**
- **第二層 · 星象字義層**：廉貞＝囚、太陰＝田宅主、暗合＝暗通。星曜宮位的「字典義」。
  知識庫的靜態資料，查表得到。
- **第三層 · 立體詮釋層**：把「巳宮廉貪忌火星」翻成「事業死忠一家、五術癢一輩子」。
  **這層是解盤的靈魂，也是偏差的來源。** 過去的失敗都在這層「亂延伸」。

前兩層機械、確定；**第三層必須被規則約束，否則就是算命仙的嘴。**

---

## 二、掛卦 ＝ attention ＋ 驗證約束（本引擎最深的一條）

同一個「象」不是單一意思，是一團「潛在意義的疊加」——
巳宮廉貪忌同時疊著：事業、心性、六親、感情四個切面。

- **象 ＝ 一個高維向量**（一團疊加的潛義）
- **命主的提問 ＝ 上下文 context / query**
- **「掛卦」＝ attention 機制**：提問像一道光，打進疊加的象裡，
  把相關的那個切面照亮選出，其餘隱去。

> 這與大語言模型的核心同構：一個 token 的義由上下文選擇性激活。
> 「一個符號承載多重潛義、由脈絡選擇性激活」是所有象徵系統的共同結構——
> 易經如此、語言如此、紫微如此、神經網路亦如此。

**危險（必須正視）：**
LLM 的 attention「準」，是因為背後有海量語料的**統計約束**。
紫微的「掛卦」若無約束，就是**事後套合**——任何問題都能從象裡掛出貌似貼合的答案。
這是命理最大的系統性騙術。

**解法：給「掛卦」加上統計約束——而本引擎的約束是「驗證紀錄」。**
- LLM 用語料統計約束哪個義被激活。
- 本引擎用**驗證過的案例**約束哪個延伸能被掛出。

因此：每個延伸必須掛驗證編號（見 V/F）、每個延伸禁區必須寫死。
**沒有驗證約束的掛卦是嘴；有驗證約束的掛卦才是引擎。**

**掛卦鐵則：命主提問決定激活哪一面；輸出時「證據力」必須隨之呈現。
高證據力可直述，中/低必須標為推測，待驗項不得當定論。**

## 三、白箱循環：這個引擎如何長大（不是「訓練」）

**釐清：這不是機器學習的「訓練模型」，是「編纂一部帶驗證等級的知識庫」。**

為何不走機器學習訓練：
1. 樣本數死牆——「命盤＋經驗證的完整人生」配對幾乎無法大量取得。
2. 標籤污染——填標籤者已看過盤，事後套合污染訓練集。
3. N=1 過擬合——單盤推出的通則，套別盤多半錯。

**正確循環（每一步的判斷都由人做、每條規則明文可查、每次修改留勘誤）：**

```
已知盤 → 用現有規則解 → 對照真實人生
  ├ 準  → 該規則證據力 +1（驗證，非訓練）
  ├ 不準 → 找適用邊界，或修規則（人判斷，非演算法自動調權重）
  └ 多盤反覆出現的新模式 → 人萃取成「候選規則」
                          → 需 ≥2 張獨立盤驗證 → 才升格為規則（S09）
```

- **黑箱模型**：規律藏在權重裡、人看不懂、無法逐條檢查、不能交代「為什麼」。
- **本引擎（白箱）**：每個判斷都能追溯到某條規則、某次驗證、某個證據力等級。
  這是它能「不唬爛」的根本。

**一句話：不是模型藉命盤訓練自己，是編纂者藉命盤，一條條有驗證地、留勘誤地，
親手把知識庫養大。LLM 從頭到尾不變，變的是知識庫的厚度與可靠度。**

擴大樣本（新的已知盤進來）＝擴大驗證，不是訓練。N=1 → N=2 是驗證樣本 +1。

## 四、知識區塊的四層格式（stars/ 等檔案的細胞結構）

每個核心知識區塊有四層，缺一則 AI 會亂延伸：

1. **結構化標頭（frontmatter）** — 給精確過濾檢索（id、化氣、tags、關聯規則）
2. **字義** — 第二層字典義
3. **延伸模板 ＋ 延伸禁區** — 第三層落地規則（防亂聯想的核心）
4. **立體投射表（一象多面 ＋ 附掛出權重）** — 確保解到位、不遺漏切面、帶證據力

範本見 `kb/stars/` 下各星檔。

## 五、為何 RAG 之前會失敗（跳重點、檢索不實）與對策

- **檢索不實根因**：語意檢索是模糊比對，分不出「巳宮貪狼」vs「亥宮借貪狼」的結構差異。
  → 對策：雙層檢索。先用 frontmatter 結構化欄位精確過濾，再語意搜。
- **跳重點根因**：撈回太多太雜，AI 抓錯重點、不知優先級。
  → 對策：解盤 SOP 強制流程（見 META-解盤SOP）＋ 區塊自帶 `優先於` 欄位。
- **根本對策**：計算歸程式（治算錯）、知識歸 RAG（治不懂）、SOP 歸元規則（治亂套）。
  三件缺一，偏差就回來。過去失敗＝只做了知識庫，缺了排盤程式與 SOP。

## 六、基礎 / 衍伸分野與延伸規則抽取（轉檔紀律）

外部教材（老師 blog、古籍、他派）進知識庫前，**先分「基礎」與「衍伸」，分層落位**。
把衍伸當基礎，解盤必歪（衍伸沒約束、又被當字典義直用＝事後套合）。

### 判別
| | 基礎 | 衍伸 |
|---|------|------|
| 落層 | 標頭＋**字義（第二層）** | **延伸規則（第三層）／立體投射（第四層）** |
| 內容 | 定義、固定位置關係、宮職本事、星曜客觀屬性（名/五行/化氣/廟旺）、機械規則 | 星入某宮的人生解讀、老師個人詮釋/強調、案例/比喻/價值判斷、斷事技法 |
| 特徵 | 跨派共識、非推論、換老師還這樣說 | 已落具體人生現象、帶詮釋、這位老師的特色 |

**判別四問**：①定義還是推論？②換派還會這樣說？③是否已落具體人生現象？④帶不帶案例/比喻/價值判斷？
**裁決預設**：拿不準歸「衍伸」（衍伸有約束、基礎沒有）。**鐵則：衍伸永不回寫成基礎。**

### 衍伸的正確用法：抽成「延伸規則」，非丟棄
衍伸不是廢料。**從 blog/教材抽出結構化延伸規則**（條件象→解讀→證據力→來源），
進第三層。這樣解盤在「已驗」與「無」之間有中間層可依循。
- 每條延伸規則必掛：**證據力**（本門教義·待驗／技法·教義／衍伸·低）＋**來源 URL/檔**。
- 老師的個案/比喻/價值判斷 → 存「特色詮釋」段，**illustration，不作證據、不成規則**。

### 解盤依循階梯（掛卦時用哪條）
```
① 已驗規則（V/F，命主實證）        → 最高，可直述
② 本門延伸規則（教材抽取，教義層）  → 中，標「本門通則·待驗」，可用但降信心
③ 無規則                          → 停，禁自由聯想（延伸禁區）
```
命主真盤一驗（②被 V/F 命中或證偽）→ 升格①或降級剔除。這就是白箱循環（三）在延伸規則上的運作。
