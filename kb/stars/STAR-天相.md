# 天相 · 化印（宰相星）

## 字義（第二層 · 基礎）
- **陽水**，**化氣為印**，**官祿主**。
- **天相是宰相，代表秩序**——心裡有一套**自己訂的生活規範**。
- 〔大耕〕化氣為印的具體意象：「**如同皇帝交辦事情後，天相去蓋章執行**」
  → 體現**法律概念與行政權威**。
- **對宮恆為破軍**（固定結構）。
- 水性主**人際連結** → 〔大耕〕天相是優秀的**中介者、媒合者**，適合社群領導與組織角色。

## ⭐ 一、定秩序四星之辨（本批最漂亮的對照）
| 星（化氣） | 它的「秩序」是什麼 |
|-----------|------------------|
| **天相（印）** | 「這是**我訂的**生活規範，**你不可隨便侵犯**」 |
| **紫微（尊）** | 「只要**讓我有面子**就可，不是什麼都要聽我的」 |
| **太陽（貴）** | 「我要訂一個規範**給所有人**，大家要聽我的，**但自己未必遵守**」 |
| **天府（權）** | 「我要**掌握一切**」 |

> 四顆星都「愛立規矩」，但**動機與適用對象完全不同**。
> 同 `R025` 固執之辨、`REF-星曜功能群` 博學星之辨——**本門一貫的「同象異因」教法**。

## ⭐ 二、官非之辨：天相 vs 文昌
> **「約定的事被更動」稱為官非**（見 `REF-名詞釋義`：官非≠打官司）。
> 與官非有關的星有二：**天相（主星）** 與 **文昌（輔星）**。

| | 管的是什麼 | 逢忌時 |
|---|---|---|
| **文昌** | **理性、邏輯、規則**——**書面文書**定下來的東西 | 文昌是**思慮**，化忌時**易有情緒上的問題** |
| **天相** | **秩序**——**人與人的約定** | **不會有情緒問題**（性質不同）|

> ⭐ **關鍵句：秩序大於規則。**
> 天相管的是人際之間的約定（更根本），文昌管的是白紙黑字（更表面）。
> 判「官非」時要先分清是**約定被破壞**（天相）還是**文書出問題**（文昌）。

## 三、逢府看相、逢相看府（三合連動）
天相與天府在**三合內**，兩星必須互看：
| 條件 | 連動 |
|------|------|
| **天府坐命** → 官祿宮為天相 | 天府要掌控生命，日常追求的事是天相 → 須為自己規範出一系列規則。**但天相若帶煞忌，工作亂七八糟又沖夫妻宮 → 人生無法在掌控中** |
| **天相坐命** → 財帛宮必天府 | 做什麼事都要有規矩；**要有規矩就要有錢**、要有足夠財務能力。**但天府須帶祿存才辦得到**（見 `STAR-天府` E4）|

> ⭐ 這一節**解釋了先前的發現**：`STAR-天府` E10「天相逢煞忌則天府格局受損」。
> 原因就在三合連動——**府的掌控要靠相的秩序去執行；相亂則府空**。

## 四、個性特質與延伸規則
| # | 條件 | 延伸解讀 | 證據力 |
|---|------|---------|--------|
| X1 | **天相怕碰煞忌** | 秩序與規則會**被破壞、或做過頭**，⚠ **但自己不會覺得**（無自知） | 教義·待驗 |
| X2 | 天相為宰相 | 與帝星相同，**喜三方四正有吉星幫忙** | 教義·待驗 |
| X3 | 注重**生活品味** | 因為要讓人感受到「一切都可照它的秩序」 | 教義·待驗 |
| X4 | **對宮破軍** | 內心充滿夢想；**遇煞忌則修改自己的規範以展現夢想** → 讓人覺得「你怎麼什麼事都做得出來」 | 教義·待驗 |
| X5 | **夫妻宮為貪狼** | 內心有夢想，對感情與工作有很多慾望；夢想與慾望交錯時，希望人生在自己可規範的範圍內；**有煞忌則做出反常之舉** | 教義·待驗 |
| X6 | **紫微天相＝造反之局** | 皇帝受身旁宰相影響，內心有夢想、工作有慾望；**現實中老闆若不給機會，我就自己來** | 教義·待驗 |
| X7 | 〔大耕〕逢煞忌之質變 | 助人的本性**倒轉為利用他人** | 教義·待驗 |
| X8 | 〔大耕〕最怕者 | 擎羊、陀羅；**化忌（尤其庚年）**；**落陷（嚴重程度視同擎羊）** | 教義·待驗 |
| X9 | 〔大耕〕逢煞忌＋天刑 | 可能有**法律糾紛** | 教義·待驗 |

### ⭐ 天相「忌」加四煞的細分（很具操作性）
| 加煞 | 表現 |
|------|------|
| **擎羊** | 努力去維持秩序，**較固執** |
| **火星** | **來得快去得快** |
| **陀羅** | 一直想「這樣對不對」，**糾結** |
| **鈴星** | 為了守住這個秩序，會**好好地謀略計畫** |

> 同一個「天相忌」，配不同煞得到四種完全不同的行為——
> 這是 `REF-煞星四煞` 兵法四句（羊疾如風／鈴徐如林／火侵掠如火／陀不動如山）的完美落地。

### 天相加魁鉞（本命 vs 運限，差別關鍵）
| 盤 / 位置 | 解讀 |
|-----------|------|
| **本命·命宮** | **自己就是魁鉞**——制定秩序規範時，希望能幫助他人 |
| **本命·官祿（三合內有魁鉞）** | 自己人生有秩序規範，工作上希望成為**大家可以信賴的人** |
| **運限·命宮** | ⭐ **運限的魁鉞是「一個人」**——此時**我就是那個人** |
| **運限·官祿** | 重視人際關係、把生活安排好，**工作上得到貴人幫助** |

> ⭐ **通則：本命的吉星是「特質」，運限的吉星是「實際出現的人」。**
> （同批次06「右弼在流財＝運限指實際有一個人」。此通則可套用到所有輔星。）

## 五、格局
- **蔭祿夾印格**〔大耕〕：天相被吉化所夾 → **一生財務安穩**（本命與運限盤皆適用）。
- **刑忌夾印**：天相被刑忌所夾 → 本引擎既有參數（別冊 S12／C 表 2027「刑忌夾印之口舌形態」）。
- **紫相＝造反之局**（見 X6，並見 `STAR-紫微` 紫相段）。

## 六、身材與外貌
教材：**修長、衣架子、小胸、四肢細細長長、腳踝可看到骨頭、皮膚偏白。**
〔大耕〕男性：慷慨助人、五官突出、**方臉、脖子短**；女性：聰慧優雅、多**嬌小、身材好**。
> ⚠ 兩處對身材的描述**方向不完全一致**（教材「修長」vs 大耕女命「嬌小」）——
> 標為**未決**，待命主向老師確認，或視為男女之別。
〔大耕〕適合職業：人資、保險、金融、業務、文書管理。

## 七、亦正亦邪（大耕的核心提醒）
> 「**聰明、長得帥、能力好，自然而然身邊的誘惑就會多。**」
> → 造成道德上的曖昧：**看起來正派，行事卻難以預測**（大耕比喻為《天龍八部》段正淳）。
> **核心教法：不要給天相固定定義——它反映的是真實的人性複雜度；
> 道德會隨時間、處境與立場而移動。**

## 八、延伸禁區
- ❌ 見天相即斷「守規矩、可信賴」——**X1：逢煞忌會做過頭或被破壞，且自己不覺得**。
- ❌ 判天相不看天府（逢相看府）、不看對宮破軍、不看夫妻宮貪狼——**三者都是它的內在張力來源**。
- ❌ 把「官非」讀成打官司，或把天相與文昌的官非混為一談（**秩序 ≠ 規則**）。
- ❌ 忽略庚年化忌（本門庚干天相忌，**派系依賴度高**）。
