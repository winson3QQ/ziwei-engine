# 太陽 · 化貴

## 字義（第二層 · 基礎）
- **陽火**，**化氣為貴**，**官祿主**。
- **父親的概念**。
- ⭐ **喜照不喜坐**（本星最重要的一句）。
- **坐命宮有刑剋父親**；女命坐命宮亦有**剋夫、剋子**的概念。
  > ⚠ 「剋」依 `REF-名詞釋義`＝**個性強悍、相處不適，不會造成他人死亡**。切勿讀成生死。
- 坐命**喜居高位**；重視社會價值與議題，關心社會經濟、局勢；**博愛、有號召力**。

## 一、旺陷（太陽是「需要在意旺落」的星）
| | 宮位 |
|---|---|
| **旺位** | 寅、卯、辰、巳、午、未 |
| **落陷位** | 申、酉、戌、亥、子、丑 |

- ⚠ **旺落程度與星曜好壞沒有直接關係**——要看**周遭環境是否適合這顆太陽**。
  （呼應 `R025`：廟旺落陷只分同級高下，不決定結構好壞。）
- **落陷的太陽**：有自己認為的規則，**願意接受灰色地帶的社會價值**，
  甚至與別人的價值觀不同。→ 不是「差」，是**另一套秩序觀**。
- **落陷的太陽比較喜歡在晚上生活**（可作定盤核對點）。
- **在意太陽旺落的星曜有二：太陰與巨門。**（其餘星不必跟著太陽的亮度走。）

## 二、⭐ 為何「喜照不喜坐」
教材給的理由很實際：
> 太陽坐命 → 十二宮都像太陽，**自己要真的去關心社會、為別人付出 → 很累**。
> 太陽在**遷移**（照命）→ **只要「看起來很像」關心社會就好，免得很累。**

**操作結論**：判太陽時，先問**它是坐還是照**——
坐命＝實質承擔（勞碌）；在遷移＝形象承擔（輕鬆）。兩者的人生負荷完全不同。

## 三、外貌（旺陷方向相反，注意勿記錯）
| | 男 | 女 |
|---|---|---|
| 共通 | 大眼、眼睛圓且明亮 | 大眼、眼睛圓且明亮 |
| **旺位** | 皮膚**偏黑** | 皮膚**偏白** |
| **落陷** | 皮膚**偏白** | 皮膚**偏黑** |
| 身材 | 高挑（台灣約 180cm 以上）| 高挑（台灣約 162cm 以上）；胸部較大 |

兩者**臉部偏圓**，**體重容易起伏、胖瘦反覆**，但多半屬於偏胖的狀態。
> 接 `PALACE-疾厄` 外貌定盤；「胖瘦反覆」是很具體的可觀察徵象。

## 四、雙星組合

### 陽梁對拱（子午）
**日麗中天格**：太陽在**午**（旺）、天梁在**子**。
| 形態 | 解讀 |
|------|------|
| **太陽在午坐命** | 十二宮都像太陽，在外又像天梁般愛幫人。**古書寫超好，但勞碌命、很累。** |
| **命坐天梁（子）、太陽在午照** | ⭐ **最佳形態**——比較不會那麼辛苦（呼應「喜照不喜坐」）|
| **太陽在子（落陷）坐命、天梁在午照** | **俗稱「阿信命格」**，做牛做馬。落陷太陽仍做得辛苦，很想幫人、制定秩序，但**領袖魅力不足**，較難取得信任與追隨 |

〔大耕·女命陽梁對拱〕一切以大局為重；**不計較、不吃醋、不小心眼**，永遠為伴侶著想，
即使付出無回報也甘願。**旺夫機制＝能自立自強、無需依賴，卻願持續付出，重承諾勝於索取。**
- **午宮**：較強勢、能力突出，但易引起反彈。
- **子宮**（落陷）：標準的犧牲奉獻型。
- 若天梁坐命，則夫妻宮為巨門 → 感情受阻。

### 陽梁同宮（卯酉）— 日照雷門格
- **關心社會**，**適合發展醫療、NGO 組織、基金會**——因為希望社會照自己的秩序走。
- 對宮空宮，**借對宮 → 表裡如一**。
- **日照雷門格**即指陽梁同宮於卯酉。

**⭐ 陽梁昌祿格（幾乎是太陽最好的格局）**
```
成格：太陽＋天梁，與【文昌】同宮或對宮，＋【化祿或祿存】
      在三方四正內也算，但【不是正格】
象  ：思路很好；命主愛唸書、博學、喜歡幫助人
```

〔大耕·女命陽梁坐命〕兩星皆帶陽剛之氣 → 女命成「**娘子漢**」：
熱心助人、有正義感；事業成就可極高（政治或專業領域）。
⚠ 但兩星**皆主六親不親** → 婚姻不易，「很多男人退避三舍」。
其長處在深具奉獻力（無怨無悔、任勞任怨），**需要願意放下姿態、有欣賞胸襟的伴侶**。

### 日月組合（辰戌對拱／丑未同宮）
〔大耕·**日月並明格**〕太陽在**辰**、太陰在**戌**（對拱），兩者皆旺：
- 兼具太陽的熱情與太陰的溫柔，**不像日月同宮那樣性格搖擺**。
- 先天傾向照顧他人：**先當別人的貴人，終獲善報**。
- ⭐ **日月旺位本身能提升整張盤的氣場**——即使他處有煞，也較能化解。
- 〔大耕〕少引人側目，**適合修行的命格**。

〔大耕·**日月同宮（丑未）**〕又稱日月照壁：
- ⚠ 核心問題是「**陰陽不定**」——兼具太陽熱情與太陰細心，他人難掌握其真實意圖。
- 表現：時而陽光時而陰沉；**若太陽落陷，可能說一套做一套**；且對自身矛盾習以為常。
- 北派認為易有「外遇雙妻」傾向（**存參，屬他派說法**）。
- 對宮若有四煞或昌曲 → **強化陰晴不定**；若能**借星到對宮旺位** → 負面顯著降低。
- ⚠ 教材補充：**日月同宮若可借對宮時，日月的旺亮度要由「對宮的地支」來決定。**

### ⭐ 日月同宮深化（批次08）——同時要扮演日月
| 太陽狀態 | 誰為主 | 表現 |
|---------|--------|------|
| **太陽在旺位** | 主為**太陽**，內心為太陰 | **外剛內柔** |
| **太陽在落陷位** | 主為**太陰**，內心太陽 | **外柔內剛** |

- 日月同宮者對宮為空宮；**若可借對宮，要記得把日月的旺陷「一起換」**
  （借過去之後，旺陷依對宮地支重算——見上一條）。
- **借不過去時，看是哪一顆煞擋著**：
  | 擋路之煞 | 結果 |
  |---------|------|
  | **陀羅** | 外剛內柔，**但內心糾結，不知到底該展現哪一種** |
  | **擎羊** | **想剛就剛、想柔就柔**（果斷，反而能自如切換）|
  > 這是「陀羅＝糾結拖磨、擎羊＝果決」在同一盤面上的乾淨對照（見 `REF-煞星四煞`）。
- 外人看：**表裡不一、難以捉摸。**
- **本命盤是一輩子的底色**，再對應運限狀況看當期表現。

### 日月同宮的兩條專用判準（只適用同宮，對拱不適用）
1. **有化權的，以化權的那一顆為主。**（⚠ 只有日月同宮這樣看。）
2. **日月對拱時**：若**對宮為身宮**（例：命宮坐太陰、身宮在遷移坐太陽），
   會**很接近日月同宮**；若**沒有身宮這個條件**，就只是「**隱性的日月同宮**」。

### ⚠ 精神健康預警（須謹慎表述）
教材列出的疊加條件：
```
丑未日月同宮 ＋ 昌曲同宮 ＋ 煞星 ＋ 福德宮出狀況 ＋ 四顆星都化忌
→ 有潛在精神方面的問題
（日月同宮＋對宮有昌曲也算；對應命宮、福德宮或疾厄宮）
```
> **使用限制**：這是**多條件同時成立**才觸發的極端疊加（教材列了五個條件），
> 屬 `R026` 煞忌交持的重症型態。
> ❌ **嚴禁**只見日月同宮或只見昌曲就作任何精神健康之斷言——
> 那是誇大風險（命主明列之推回情境），且違反「條件未用盡不下判斷」。
> 命理不作醫療診斷；此條僅作**結構風險提示**，任何實際疑慮應循醫療專業。

## 五、三吉加會（與太陰共用，見 `STAR-太陰`）
**三吉加會＝三方四正內有祿權科，且要擺在正確的宮位上。**
> **正式擺法：化科在命宮、化權在官祿宮、化祿在財帛宮。**
- **落陷太陽**遇三吉加會 → 容易**打腫臉充胖子**。
- （對照）**落陷太陰**遇三吉加會 → **偷偷賺大錢**。

> ⚠ 這條把「三吉加會」從模糊的吉兆變成**有位置要求的格**——
> 不是三方四正裡有祿權科就算，**位置不對不成格**。此點嚴格，勿放寬。

## 六、延伸禁區
- ❌ 把「剋父／剋夫／剋子」讀成生死（見 `REF-名詞釋義`：指相處不適）。
- ❌ 見太陽落陷即斷差——**落陷只是另一套秩序觀，且需看環境是否適合**。
- ❌ 忘記「喜照不喜坐」：坐命與在遷移，勞碌程度天差地別。
- ❌ 男女旺陷的膚色方向記反（男旺黑／女旺白）。
- ❌ 見祿權科就稱三吉加會（須位置正確才成格）。
