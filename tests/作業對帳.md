# 作業對帳（引擎測試集）

> **用途**：以課程作業的標準答案，檢驗知識庫是否正確編碼了本門的解盤方法。
> 這驗的是**引擎忠實度**（KB 有沒有把本門方法編對），
> 與《驗證與方法論別冊》的 V/F（規則是否對應命主現實）**是兩種不同的驗證**。
>
> **判定分級**
> - `盲測`：命主先給題、AI 先答並自報引用、之後才開獎 → **可作命中率證據**
> - `教材對答`：題目與答案同時給出 → **僅能 audit 知識庫缺漏，不作命中率證據**
>   （依別冊方法論警語：算數者唯二為事前盲測與未到期預測）
>
> **差異診斷四類**：① 知識庫缺規則 ② 知識庫抄錯 ③ 我套用錯誤 ④ SOP 缺口
> 每一處差異都必須產出**具體檔案修改**，不得只記「下次注意」。

### Q16 詳解（命主本命紫微 · 在命宮丑）
**三方四正核算**（`PALACE-宮位系統` 對照表：命宮＝命・遷移・財帛・官祿）
| 宮 | 支 | 星曜 |
|---|---|---|
| 命宮 | 丑 | **紫微・破軍** ＋ 擎羊・地劫・華蓋・八座・三台 |
| 遷移(對) | 未 | 天相 ＋ 天虛 |
| 財帛 | 酉 | 武曲・七殺 ＋ 地空・**右弼**・蜚廉・鳳閣 |
| 官祿 | 巳 | 廉貞・貪狼 ＋ 火星・**天鉞**・**左輔**・天馬・龍池 |

**團隊六星核算**：天鉞✅(巳)、左輔✅(巳)、右弼✅(酉)、天相✅(未·對宮) → **會到 4/6**；
**缺天魁、天府**，且兩顆都在**福德宮(卯)**，不在命宮三方四正。
**祿羊陀**：祿存**子**(兄弟)、擎羊**丑**(命宮·同宮)、陀羅**亥**(夫妻)
→ **命宮正落在擎羊位；祿存在隔壁兄弟宮，不入命宮三方四正。**
**煞**：擎羊・地劫(命)、地空(財)、火星(官) ＝ 4 顆（四煞2＋空劫2）

**依 `R030` 果菜榨汁機合成**：
1. **主星紫微**（前主後輔）＝帝星、化氣為尊；帝在命宮 → **要作主、要尊貴、要面子的是本人**（非 Z3「他貴你賤」）。
2. **次星破軍**＝耗、大破大立 → **紫破＝追求夢想的皇帝**；破軍對宮必天相，水性帶桃花，**可解皇帝之孤**。
3. **輔星**：得**左輔＋天鉞（官祿）、右弼（財帛）、天相（遷移）**——
   ⭐ **檯面下的貴人（鉞）有，檯面上的（魁）沒有；有人幫，但沒有庫（缺天府）。**
   且輔弼**分落官祿與財帛、且各自逢煞**（左輔逢火星、右弼逢地空）→ 依 S10/`R021`，
   **兩顆輔星皆為「攪局警示」而非貴人**（此與別冊 V12 已驗結論一致）。
4. **煞**：**擎羊同宮**——`R025` 煞星的固執偏情緒、`REF-煞星四煞` 羊為「疾如風」果決
   → 與紫微之尊、破軍之耗合成＝**決斷快、行動猛，但帶情緒性的堅持**。
   **地劫同宮**——依 `STAR-破軍` B7，空劫可降低破軍衝動 → 有節制作用。
   **華蓋同宮**——宗教五術之緣。
5. **對宮天相**：在外被視為**講規矩、重秩序、可託付印信**之人。
   → ⭐ **核心張力：命宮要破（紫破·破舊立新），遷移要立規矩（天相·印）——內破外守。**
6. **祿的位置**：⭐ **祿存在子（兄弟宮），命宮拿到的是刀（擎羊）不是祿。**
   → 祿存乘旺的是兄弟宮天機，**命宮得不到乘旺**。

**綜合判讀**：帝星坐命而**團隊不全（缺魁、府）、輔弼皆逢煞、祿不入命、羊劫同宮**
→ 依 `STAR-紫微` Z1/Z2，**不至於是「落難皇帝」（仍有鉞、相、輔弼會照），
但屬「自己扛的皇帝」**：資源要自己生、貴人多是檯面下的、熱心者需過濾。
配破軍之夢想與擎羊之果決 → **開創型、行動快、靠自己**；
